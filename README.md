# 硬点 / HARDPOINT

一个用 Godot 制作的单人 3D 摸金射击游戏。搜刮三层设施，带着战利品继续探索，或者从每层入口应急撤离。

## Windows 试玩

在 [Releases](https://github.com/s-z-h1122/first-rtestepo/releases) 下载 Windows x64 试玩包，完整解压后双击 **开始游戏.exe**。试玩包包含所需的 Godot 运行文件。

- WASD 移动，鼠标转视角；左键射击，右键瞄准。
- 按住 E 搜索或撤离，Tab 查看背包，B 打开补给商店。
- 撤离后金币存入本地仓库，可在整备大厅兑换下一局的补给。
